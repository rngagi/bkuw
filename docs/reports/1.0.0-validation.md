本報告記錄 `1.0.0` 版本準備前的程式與文件驗證。版本號提交及 GitHub Actions 安裝包結果會在本報告之後產生；公開狀態以 [GitHub Releases](https://github.com/rngagi/bkuw/releases) 為準。

## 自動驗證

| 命令 | 結果 |
|---|---|
| `pnpm check` | 通過：TypeScript、Rust format、Clippy 無錯誤 |
| `pnpm test` | 通過：23 個 test files、105 個 tests |
| `pnpm test:rust` | 通過：84 個 tests；1 個真實 XeLaTeX test 依設計 ignored，交由 portable-template CI job 執行 |
| `pnpm test:e2e:build` | 通過：release-mode E2E app 建置完成 |
| `pnpm test:e2e` | 通過：2 個 specs、4 個 tests |
| `pnpm tauri build --no-bundle` | 通過：產生 macOS Apple Silicon release binary |
| 本機 Markdown link checker | 通過：18 份文件的相對連結目標存在；唯一的相對錨點對應 `產品規格` 既有標題 |
| `git diff --check` | 通過 |

本機 Node.js 是 22.15.0，低於 [`package.json`](../../package.json) 要求的 Node 24，因此 pnpm 在各命令前顯示 engine warning；命令本身全部成功。GitHub Actions 依 workflow 使用 Node 24。

WebdriverIO 啟動時輸出 `tauri-driver not found` 與 session 結束後 mock-store 清理 warning；兩個真實 WebView session 仍成功建立，app workflow 3 項與 audio workflow 1 項全部通過。報告保留這些診斷，供後續升級 Tauri WebDriver service 時複查。
