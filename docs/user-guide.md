# bkuw 使用指南

## 建立或開啟專案

啟動 bkuw 後可建立空白專案、從 UTF-8 CSV 建立專案，或開啟既有 `.bkuw` 目錄。新專案必須設定主要書寫系統；其他書寫系統、分析語言、詞性與語意類別可稍後在設定中調整。

CSV 匯入會先偵測分隔符號並顯示欄位對應與預覽。確認問題列、相鄰列分組及寫入位置後才會建立專案；失敗不留下半成品。

## 編輯詞條

左側列表用於搜尋和選擇詞條，右側編輯完整詞條。詞條由各書寫系統的表記、依序排列的義項、例句、root/base 關係與詞條註記組成。詞性屬於義項；例句可有多個書寫系統表記。

有效變更會自動儲存；`Ctrl+S`（Windows）或 `Cmd+S`（macOS）會立即儲存。刪除詞條後可立即復原。文字以 NFC 保存，搜尋比對可以折疊大小寫與附加符號，但畫面文字不會因此被改寫。

## 相片與音檔

相片屬於義項。可匯入 PNG、JPEG 或 WebP；過大的圖片會先在本機縮小，再以專案內 PNG 保存。

音檔屬於義項或例句。可匯入 WAV、MP3、M4A/AAC、FLAC、OGG/Opus、AIFF 或 WebM，也可直接錄音。bkuw 在本機轉成單聲道 WebM／Opus；來源檔不會被修改。每個來源上限 256 MiB、30 分鐘，錄音暫存上限 64 MiB。播放、匯入與錄音同時只啟用一項。

詳細格式與擁有權規則由[產品規格](product-spec.md#義項與例句音檔)維護。

## 排序

自動排序可依書寫系統或第一個非空語意類別分組。書寫系統排序可設定自訂字母表；沒有自訂字母表時使用 Unicode collation。手動排序可混合小標與詞條，新增或恢復而尚未排入的詞條會標示待處理。

工作區、LaTeX／PDF 匯出與公開網站都使用專案目前的排序及小標。「自訂」排序會保留手動結果，不會由發佈或匯出重新排列。

## 匯出

「匯出」提供 corpus CSV、LaTeX 原始碼、Overleaf ZIP 與本機 PDF。精靈會先建立資料快照並檢查必要欄位、字型及本機 XeLaTeX；返回設定後必須重新檢查。完整步驟見[匯出指南](export-guide.md)，CSV 欄位見[rngagi-corpus v0.3 契約](corpus-csv-contract.md)。

## 發佈網站

「設定並發佈」精靈會引導完成 Cloudflare 帳號、R2、Account ID 與最低權限 API Token 設定。網站使用 `https://<worker-name>.<account-subdomain>.workers.dev/`；R2 bucket 固定為 `<worker-name>-media`。首次成功後 Worker 與 bucket 名稱鎖定，之後使用「更新網站」。

發佈前可設定標題、固定介面語言、關於內容、公開的書寫系統、notes 與 relations。檢查頁會顯示資料數量、媒體差異、阻擋問題、完整網址及各階段進度。bkuw 只在按下「發佈」時上傳；Token 存入系統 credential store，失敗時只在本次程序記憶體中保留。

公開網站使用專案排序，支援搜尋、deep-link、亮暗主題、圖片與音檔。部署通過線上檢查後才清除不再使用的 R2 媒體；清理失敗不會撤回已可用的網站。

## 備份與搬移

關閉專案後完整複製 `.bkuw` 目錄。不要只複製 `project.sqlite`，因為相片與音檔位於 `media/`。搬到另一台電腦後，Cloudflare 發佈設定與公開網址仍在專案中，但 API Token 必須重新連接。
